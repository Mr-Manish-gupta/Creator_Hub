#Creator hub

## 📖 About 
This platform allows creators to upload and sell digital 
products while customer can browse, purchase and instantly download them.It provides secure file management, user authentication, and an esay-to-use marketplace for digital content.


## 💪 Features 
- Security
- Upload Digital Products
- Secure File Storage
- Instant Download After Purchase
- Order history

## 🔧 Tech Stack 
- Java
- Spring boot
- React
- MySQL
- Maven
- JWT
- Tailwind CSS

##  🌐 Live Demo 
https://creatorhub-share.netlify.app/

## ⚙️ Installation 
1. Clone repository
2. Install dependency
3. Run Backend
4. Run Frontend
